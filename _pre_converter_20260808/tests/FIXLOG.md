# FIXLOG — abc2xml conformance campaign

- CONF-lines-1 (D31): unknown/consumed note decorations no longer sprayed onto every later note — `staffDecos` gained a `fromNote` flag so decorations arriving from a note are consumed or dropped (with an `info` warning), never re-queued onto `s.nextdecos`; `doNotations`' fall-through no longer emits phantom `<other-articulation>` elements. Functions touched: `doNotations`, `staffDecos`.

- CONF-ornaments-1 (D95): `~` (Irish roll) now emits a real ornament — `'roll':'other-ornament'` added to `ornMap`, and the `doNotations` ornament branch names an empty `<other-ornament>` after the decoration (`<ornaments><other-ornament>roll</other-ornament></ornaments>` on the decorated note only, zero `<other-articulation>`). Functions touched: `Music.ornMap` (class table), `doNotations`.

- CONF-structure-repeats-1: measure-numbering pollution fixed — `s.measureNumbering` now initialises to `''` (falsy, "no directive seen") instead of the truthy `'no'`, so conversions with no directive emit zero `<print><measure-numbering>` blocks; and `mkMeasure` now peeks at the measure's leading inline `I:` fields (`barnumbers` / `measurenumbering`) before emitting the print block, so a body-placed `%%barnumbers 1` takes effect from its own measure (barnumbers.abc: yes x4, none x0). Functions touched: `Music.reset` (init at ~1008), `mkMeasure`.

- CONF-ornaments-2: extended trill spans now emit real `<wavy-line>` — new explicit branch in `doNotations` for `trill(` / `trill)` / `wavy-line(` / `wavy-line)` (before the generic `ornMap` branch, in the glissando/slide span idiom) emits `<ornaments><wavy-line number type='start|stop'/>` on the decorated notes, backed by a new `s.wavynum` counter reset per part; `!trill(!` no longer produces an invalid `trill-mark@type=start`, `!trill)!`/`!wavy-line)!` no longer fall to the drop fallback. NOTE for future agents: `gen_expected.py`'s OVERRIDES still carried stale xfail entries for the already-fixed CONF-lines-1 / CONF-ornaments-1 / CONF-structure-repeats-1 — regenerating clobbered those four hand-strengthened guards; they were restored verbatim in expected.json (only the two CONF-ornaments-2 probes changed net). Functions touched: `doNotations`, `mkPart` (wavynum init).
- CONF-articulations-breaths-1: !shortfermata!/!longfermata! now put the shape in the fermata element text (angled/square per the MusicXML fermata-shape enum) instead of an invalid shape= attribute. Functions touched: doNotations (deco dispatch in mkNote path, abc2xml.py ~line 1411).
- CONF-articulations-breaths-2: !invertedfermata! (standard ABC 2.1) now emits `<fermata type='inverted'/>` on the decorated note — new explicit branch in the doNotations deco dispatch alongside the H/longfermata/shortfermata cases; previously it fell through to the D31-class fallback and sprayed other-articulation='invertedfermata' onto every note event including rests (probe now: 1 inverted fermata on the first note, 0 other-articulation). Functions touched: doNotations (deco dispatch, abc2xml.py ~line 1417).
- CONF-structure-repeats-2: anacrusis detection — first measure shorter than the metre is now emitted as number="0" implicit="yes" and all later bar numbers shift down by one (per-part pickupOff offset; explicit %%setbarnb still wins). Functions touched: mkMeasure, mkPart.
- CONF-structure-repeats-3: %%segno/%%tocoda/%%dalsegno/%%dacapo/%%fine (and inline [I:...]) sound-jump directions now carry a real <direction-type> — segno gets the <segno/> glyph, the rest get <words> (D.C. / Fine / D.S. / To Coda) in the capoMap idiom (placement above, <sound> appended to the direction after the direction-type), so the emitted <direction> is schema-valid and the mark is visible. Also fixed the guard `if s.maat:` -> `if s.maat is not None:` in those five branches — Element truthiness means an empty measure is falsy, and once CONF-structure-repeats-1 stopped stuffing a <print> into every measure these directives silently emitted NOTHING (the old "5 sound-only directions" behaviour had been riding on that pollution). Functions touched: doField_I (the dacapo/fine/segno/dalsegno/tocoda branches, abc2xml.py ~2501-2529).
- CONF-pitch-staff-4: M:C / M:C| now emit <time symbol='common'/'cut'> (was plain 4/4 / 2/2 with no symbol attribute); handled at the single meter-emission point in doFields, so header M: and inline [M:] both covered. Functions touched: doFields.
- CONF-pitch-staff-1: added 'aeo' (offset 11, = minor) and 'ion' (offset 8, = major) to offTab/modTab so K:Xaeolian/K:Xionian resolve to the correct fifths and emit mode=aeolian/ionian instead of falling back to major. Functions touched: class-level tables offTab/modTab (MusicXml class constants, abc2xml.py ~line 934).
- CONF-pitch-staff-3: `K:<tonic> exp` now yields an explicit-only signature — detect `exp` as the mode token in the K: handler, zero `fifths` and clear `s.keyAlts` before the listed accidentals are applied, so the tonic's own signature no longer leaks through. Functions touched: MusicXml.doFields (K: field branch).
- CONF-pitch-staff-2: key-octave now emits the 1-based key-step index in @number with the octave as element text (was octave-in-@number with empty text). Functions touched: doFields (K: field handling, custom key-signature branch).
